# Everything Automation

A learning project focused on automated software testing using Python, pytest, and Playwright.

## Project Overview

This repository contains automated tests I am developing while learning UI test automation.

The `sample-app/` directory contains the web application provided by the FreeCodeCamp testing course and is used as the application under test.
check out there YouTube video here: https://www.youtube.com/watch?v=jydYq7oAtD8&list=WL&index=14&t=3492s, and repo the provided - https://github.com/beaucarnes/software-testing-course/tree/main


The `testing/` directory contains my Python-based test automation implementation using:

- Python
- pytest
- Playwright
- pytest-playwright

The purpose of this project is to learn automated UI testing and translate the concepts demonstrated in the course's JavaScript/Playwright examples into Python.

## Attribution

The sample web application was provided by the FreeCodeCamp testing course and is not my original application.

My contributions to this repository primarily consist of the Python test automation, test configuration, and related testing infrastructure.
